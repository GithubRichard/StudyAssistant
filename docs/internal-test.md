# 网页版 v1 内测说明

目标：在只有一台云服务器（IP+端口直连，无备案、无域名）的情况下，
让家长/孩子用浏览器完成「提交作业 → 批改 → 复习台账」的完整闭环。

## 一、准备（服务器上，3 步）

```bash
# 1. 复制配置
cp config.example.yaml config.yaml

# 2. 生成网页账号（一个账号 = 一个孩子，可重复执行添加多个）
python3 scripts/make_web_user.py --username kid1 --display-name 老大
# 按提示输入两次密码，把输出的片段粘贴到 config.yaml 的 web.users: 下面

# 3. 启动（内测建议先用前台模式看日志）
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问：`http://服务器IP:8000/`

- HTTP 直连只建议在可信网络下内测；公网长期使用请配置 HTTPS（域名+反代，二期）。
- `config.yaml` 不进版本库，改完配置需重启服务。

## 二、冒烟测试清单

1. 打开页面 → 应跳到登录页，标题为配置的 `web.title`。
2. 用错的密码登录 → 提示"用户名或密码不正确"（不区分用户名/密码错误）。
3. 用正确账号登录 → 进入「今日学习台」。
4. 学习页 → 拍作业：选学科、传一张作业照片、提交 → 任务状态页轮询 → 自动跳批改结果页。
   - 错题和存疑题在上、默认展开；答对的题折叠。
   - 任一错题点「我觉得判错了」→ 确认后按钮变"已标记异议"，台账状态不变。
5. 学习页 → 生成训练：选"按知识点"填知识点 → 提交 → 任务完成后进做题页（一题一屏）。
   - 点「做错了」→ 提示"已记入复习台账"；做完后去复习页能看到这道题（待订正）。
6. 复习页 → 点一条错题 → 详情页点「记为已订正」→ 状态变"待复测"；再点「复测通过」→ 变"已通过"。
7. 我的页 → 改学科、设学期起始日期 → 保存成功；退出登录 → 回到登录页。

## 三、数据保留说明

- 错题台账按账号保留 **2 年**（`retention_days: 730`），超期错题及关联的订正/复测事件由每日定时任务自动清理。
- **任务记录、附件、GitHub 归档不受影响**，不会被清理。
- 如需调整保留期，改 `config.yaml` 的 `retention_days` 后重启。
