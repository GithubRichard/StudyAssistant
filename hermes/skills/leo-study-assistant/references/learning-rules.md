# 学习记录规范（服务端版）

工作区 `README.md` 存在时以它为准；缺失时使用本文件，并在结果中注明「工作区规范缺失，使用技能内置规范」。
本文件用于初始化新工作区的 `README.md`，**不含历史学习记录、学生个人信息或本机路径**。

学习闭环：**每日错题解析 → 周报归纳 → 专项或考前训练 → 实际复测 → 更新记录**。

## 目录结构与命名

```text
<工作区根>/
├── README.md
├── .gitignore                              （原题资料不上传的忽略规则）
└── <账号>/                                  （一个账号 = 一个孩子，归档按账号隔离）
    ├── 语文/{错题解析,强化训练,周报分析}/    （按任务类型对应子目录）
    ├── 数学/{错题解析,强化训练,周报分析}/
    ├── 英语/{错题解析,强化训练,周报分析}/
    └── <学科>/原题/年份/周次/                （仅本地，不随仓库分发）
```

| 目录 | 用途 | 命名规则 |
| --- | --- | --- |
| `<账号>/<学科>/错题解析/` | 当天各份作业的错题解析与学习问答 | `YYYY-MM-DD.md`，每学科每天一个文件，同日新增来源合并 |
| `<账号>/<学科>/周报分析/` | 一周的问题归纳、进步与行动清单 | `YYYY-MM-DD.md`，用首次生成日期，正文标明覆盖区间 |
| `<账号>/<学科>/强化训练/` | 专项、月考、期中考、期末考训练及复测 | `YYYY-MM-DD-主题.md`；同日同主题更新原文件，独立批次加 `-第2组` |
| `<账号>/<学科>/原题/年份/周次/` | 原始试卷、作业照片，**仅本地保留** | 按「年份/周次」归档；不提交、不推送、不进 PDF 附件 |

新增学科沿用同一套子目录。空目录用 `.gitkeep` 占位，不预填虚构记录。
账号目录由服务端按身份派生（网页账号 `web:leo` → `leo`，微信身份加 `wx-` 前缀），**不要**自行拼账号层。
原题目录与 `.gitignore` 由服务端骨架创建；**不要**把原题复制出该目录、不要写进归档正文。

> 产出结果时，`archive.suggested_path` 只写**三段**：`学科/子目录/文件名.md`（不含账号层）。
> 账号层由业务后端按当前任务身份前置拼接，你只需要给出工作区内的相对位置。

## 任务识别与读取范围

| 输入 | 默认读取范围 |
| --- | --- |
| 作业图片 | 本次图片、当天已有记录及必要历史 |
| 月考（`training_kind=monthly`） | 当月第一天至今天 |
| 期中考 / 期末考（`midterm` / `final`） | 本学期开学至今天；开学日期未知时如实说明缺口 |
| 周报 | 用户指定区间；未指定为本周一至今天，并说明区间 |
| 专项训练（`topic`） | 相关错题与复测记录，不强行限定区间 |
| 复测 | 关联的训练与作答记录 |

- 实际使用的区间由服务端计算并写入 `scope`；用户明确指定的区间与考试范围优先，覆盖默认值。
- 同一错题按来源、日期、页码、题号关联去重，不因同时出现在日解析与周报而重复计数；再次实际作答才算新的复测或出错事件。
- 按正文覆盖区间筛选周报，而非只看文件名。
- 历史资料缺失时说明缺口；**没有记录不等于没有错误，更不等于已经掌握**。

## 每日解析内容模板

1. **当日概览** — 学科、批改日期、检查份数、确认错题数、未作答数、存疑数；范围不足时注明。
2. **来源信息** — 每份作业的练习名称、页码、题号范围；跨页题的页码写起始页并注明区间（如「P12-13」）；未知信息标记未提供。
3. **逐题解析** — 来源、页码题号与必要题干（跨页题合并成一条，页码写起始页，区间在题干或证据里注明）；
   孩子原答案、正确答案与分步思路；知识点与具体错因规则；
   订正与复测状态（待订正／已订正待复测／复测通过／复测未通过，附实际日期与关联训练）。
4. **未作答与存疑题** — 单列并说明原因与待核实事项，不猜测、不默认为答错、不删除。
5. **做得好的题** — 记录有依据的进步、正确思路与良好习惯。
6. **概念问答** — 当日疑问与解释，关联题目；没有则注明无。
7. **当日重点** — 需订正、复习或复测的知识点，供周报与考前训练使用。

## 周报模板

1. 本周概览（区间、来源、份数、错题数、未作答数、存疑数、资料缺口）
2. 错题明细（按来源与知识点，重点写重复错因与变化，不整篇复制日解析）
3. 做得好的题（结合订正与复测记录说明进步）
4. 概念问答整理
5. 错误类型归纳（按根因归类并注明统计口径与可能重叠）
6. 下周行动清单（可勾选任务，说明知识点与检查方式）

## 训练模板

1. 训练目标与资料范围（含是否仅为已归档错题专项训练）
2. 问题依据（链接原始错题、周报与复测结果）
3. 分层题目（基础巩固、同类变式、适当综合应用）
4. 独立答案解析区（与题目分开，便于先独立完成）
5. 实际作答与复测结果（未收到作答时标待完成／待复测）
6. 下一步建议（继续练习或间隔复测，不无限重复已改善的问题）

## 训练与复测规则

- 先按默认规则或用户指定筛选范围，再结合训练与复测记录判断；优先安排反复出错、尚未订正、复测未通过的知识点。
- 每道题或题组关联知识点与历史依据；用变式题检查规则能否迁移，不只换顺序照抄原错题。
- **生成练习不等于完成练习，完成订正不等于已经掌握；答对一次也不代表稳定掌握。**
- 没有新结果时保留待复测状态，并保留此前复测未通过的事实。
- 历史不足时说明可覆盖范围与缺口；补充的通用巩固题须明确标注，不伪称来自孩子的历史错误。
- 错误率只在分母（已检查题数）可确认时计算；多标签分类注明可能重叠，不把类别次数当作独立错题总数。

## 隐私与边界

- 只归档必要的学习信息；不复制学校、班级、联系方式、住址等无关个人信息。
- 上传的作业照片只用于本次分析：不复制到输出目录、不写入归档 Markdown、不作为附件交付、不进入 Git。
- 原题资料一律不进入 Git、不进 PDF 附件、不外发。
- 不修改他人历史记录，不因重试或重复识图新增出错事件。
- 学习记录与结论必须与原始材料一致；存疑项不得在无依据时标为已解决。
- 归档落盘、Git 提交推送、邮件发送**由业务后端执行**；技能不执行这些动作，也不声称已完成。
