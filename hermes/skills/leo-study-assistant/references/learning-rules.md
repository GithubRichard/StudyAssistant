# 学习记录规范（服务端版）

工作区 `README.md` 存在时以它为准；缺失时使用本文件，并在结果中注明「工作区规范缺失，使用技能内置规范」。本文件用于初始化新工作区的 `README.md`，**不含任何历史学习记录、学生个人信息或本机路径**。

## 目录结构与命名

```text
<工作区根>/
├── README.md
├── 语文/{错题解析,强化训练,周报分析}/
├── 数学/{错题解析,强化训练,周报分析}/
├── 英语/{错题解析,强化训练,周报分析}/
└── <学科>/原题/年份/周次/     （仅本地，不随仓库分发）
```

| 目录 | 用途 | 命名规则 |
| --- | --- | --- |
| `学科/错题解析/` | 当天各份作业的错题解析与学习问答 | `YYYY-MM-DD.md`，每学科每天一个文件，同日新增来源合并 |
| `学科/周报分析/` | 一周的问题归纳、进步与行动清单 | `YYYY-MM-DD.md`，用首次生成日期，正文标明覆盖区间 |
| `学科/强化训练/` | 专项、月考、期中考、期末考训练及复测 | `YYYY-MM-DD-主题.md`；同日同主题更新原文件，独立批次加 `-第2组` |
| `学科/原题/年份/周次/` | 原始试卷、作业照片，**仅本地保留** | 按「年份/周次」归档；不提交、不推送、不进 PDF 附件 |

新增学科沿用同一套子目录。空目录用 `.gitkeep` 占位，不预填虚构记录。

## 任务识别与读取范围

| 输入 | 默认读取范围 |
| --- | --- |
| 作业图片 | 本次图片、当天已有记录及必要历史 |
| 月考 | 当月第一天至今天 |
| 期中考 / 期末考 | 本学期开学至今天 |
| 周报 | 用户指定区间；未指定为本周一至今天，并说明区间 |

- 用户明确的学科、日期区间、考试范围优先于默认值。
- 同一错题按来源、日期、页码、题号关联去重，不因同时出现在日解析与周报而重复计数；再次实际作答才算新的复测或出错事件。
- 按正文覆盖区间筛选周报，而非只看文件名。

## 每日解析内容模板

1. **当日概览** — 学科、批改日期、检查份数、确认错题数、未作答数、存疑数；范围不足时注明。
2. **来源信息** — 每份作业的练习名称、页码、题号范围；未知信息标记未提供。
3. **逐题解析** — 来源、页码题号与必要题干；孩子原答案、正确答案与分步思路；知识点与错因规则；订正与复测状态。
4. **未作答与存疑题** — 单列并说明原因和待核实事项，不猜测、不默认为答错、不删除。
5. **做得好的题** — 记录有依据的进步、正确思路与良好习惯。
6. **概念问答** — 当日疑问与解释，关联题目；没有则注明无。
7. **当日重点** — 需订正、复习或复测的知识点，供周报与考前训练使用。

## 周报模板

1. 本周概览（区间、来源、份数、错题数、未作答数、存疑数、资料缺口）
2. 错题明细（按来源与知识点，重点写重复错因与变化，不整篇复制日解析）
3. 做得好的题（结合订正与复测记录说明进步）
4. 概念问答整理
5. 错误类型归纳（按根因归类并注明统计口径与可能重叠）
6. 下周行动清单（可勾选任务，说明知识点与检查方式）

## 训练与复测规则

- 先按默认规则或用户指定筛选范围，再结合训练与复测记录判断；优先安排反复出错、尚未订正、复测未通过的知识点。
- 每道题或题组关联知识点与历史依据；用变式题检查规则能否迁移，不只换顺序照抄原错题。
- **生成练习不等于完成练习，完成订正不等于已经掌握；答对一次也不代表稳定掌握。**
- 没有新结果时保留待复测状态，并保留此前复测未通过的事实。
- 历史不足时说明可覆盖范围与缺口；补充的通用巩固题须明确标注，不伪称来自孩子的历史错误。

## 隐私与边界

- 只归档必要的学习信息；不复制学校、班级、联系方式、住址等无关个人信息。
- 原题资料一律不进入 Git、不进 PDF 附件、不外发。
- 不修改他人历史记录，不因重试或重复识图新增出错事件。
- 学习记录与结论必须与原始材料一致；存疑项不得在无依据时标为已解决。

## 新工作区初始化

工作区为空时：创建上述目录骨架与 `README.md`（内容取自本文件），在结果 `missing_info` 中说明「工作区尚无历史资料，无法参考既往错题与复测记录」，**不得虚构历史**。
