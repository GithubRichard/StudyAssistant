# 作业批改小程序 · 前端说明

后端代码在上一级目录（`app/`），先看 `../README.md` 把后端跑起来。

## 导入到微信开发者工具

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram` 目录
2. 填入你的小程序 **AppID**（`project.config.json` 里也要改）
3. 打开 `utils/config.js`，把 `BASE_URL` 改成你的服务器地址

## 本地调试

- 开发者工具 → 详情 → 本地设置 → 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
- 这样 `http://电脑IP:8000` 也能调通（手机预览需与电脑同一 Wi-Fi）

## 上线前

1. 域名完成 **ICP 备案**（个人非经营性备案，云服务商后台免费办）
2. 服务器配好 HTTPS（见 `../README.md` 的 Caddy 方案）
3. 小程序后台 → 开发管理 → 开发设置 → 服务器域名，添加 `https://api.你的域名`
4. 取消「不校验域名」勾选，完整跑一遍再提交审核

## 页面一览

| 页面 | 功能 |
|---|---|
| pages/index | 拍照/选图 → 选科目年级 → 上传批改 |
| pages/result | 轮询批改进度，展示每题对错、讲解、知识点，可加入错题本 |
| pages/history | 批改历史记录 |
| pages/mistakes | 错题本 |
| pages/mine | 剩余次数、在线模型、服务器地址 |

注意：结果页有醒目的「AI 批改仅供参考」提示，上线审核建议保留。
