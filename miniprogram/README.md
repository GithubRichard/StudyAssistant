# 学习助手小程序 · 前端说明

后端代码在上一级目录（`app/`），先看 `../README.md` 把服务跑起来。

## 导入到微信开发者工具

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram` 目录
2. 填入小程序 **AppID**
3. 打开 `utils/config.js`，把 `BASE_URL` 改成你的**业务后端**地址

> 这里只填本服务地址。Hermes 地址与密钥属于服务端内部配置，**不要**出现在小程序里。

## 本地调试

- 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
- 手机预览需打开调试模式才能访问未备案域名

## 登录与会话

- `app.js` 启动时调用 `wx.login` 换会话令牌，令牌存本地并在请求头 `Authorization: Bearer` 中携带
- 令牌失效（401）时自动重新登录并重试一次
- 「我的」页可查看当前 openid，便于加入服务端 `auth.allowed_openids` 白名单

## 提交任务

- 首页支持任务类型：作业批改 / 学习问答 / 周报分析 / 针对性训练 / 复测
- 针对性训练可再选 **专项 / 月考 / 期中 / 期末**，并可填写**考试范围**（不填则只做基于已归档错题的训练）
- 资料区间由服务端按规范计算（月考=当月 1 日至今、期中期末=本学期开学至今、周报=本周一至今），首页显示默认区间，可手动覆盖
- 学科、年级来自「学习设置」，可选「未指定」；系统不会替你假定年级与学科
- 图片逐张上传并显示状态（待上传/上传中/已上传/失败），失败重试不会重复上传已成功的图片
- 提交时带 `Idempotency-Key`，网络抖动重试不会重复创建任务、也不会重复扣次
- **原题照片只用于本次批改**：存在服务端私有目录，不写入学习记录、不进入 Git、不随记录分发

## 结果页状态

| 状态 | 含义 | 可以做什么 |
|---|---|---|
| 排队中 / 执行中 | 服务端正在执行 | 可离开页面，返回后自动继续查询 |
| 待补充材料 | 结果已产出但缺材料 | 在页面底部提交补充材料，开启新一轮 |
| 结果未确认 | 超时或服务重启 | 不会自动重试；可补充材料后重发 |
| 失败 | 协议校验或调用失败 | 查看原因后重新发起 |
| 已完成 | 正常结束 | 查看五态结果、核查状态、下载成果 |

题目五态：答对 / 答错 / 未作答 / 待核实 / 未处理。判错题才显示「加入错题本」。

订正与复测：待订正 / 已订正待复测 / 复测通过 / 复测未通过。错题与存疑题可在此直接**登记复测结果**
（只记录真实发生的作答，会追加到归档记录，不改写历史判定）。

交付状态按真实结果展示：归档、PDF、邮件、学习记录同步；未启用或失败都会如实标注，
同步冲突时显示冲突记录文件名（不代表冲突已解决）。

## 复习台账

- 按学科与订正状态筛选（全部 / 待订正 / 待复测 / 复测未通过 / 复测通过）
- 每条显示来源页码题号、孩子原答案、正确答案、错因规则、归档路径与最近更新时间
- 底部弹层登记复测结果（通过 / 未通过 / 已订正待复测），并说明是否追加到归档文件
- 空状态明确提示「历史不足时保留缺口，不补造记录」

## 上线前

1. 域名完成 **ICP 备案**
2. 服务器配好 HTTPS（见 `../README.md`）
3. 小程序后台 → 开发管理 → 服务器域名，添加 `https://api.你的域名`（`request` 与 `uploadFile` 都要加）
4. 取消「不校验域名」勾选，完整跑一遍再提交审核
5. 服务端把允许使用的 openid 填入 `auth.allowed_openids`

## 页面一览

| 页面 | 功能 |
|---|---|
| pages/index | 任务类型、训练类型、考试范围、资料区间、多图上传、文字说明、学科年级 → 提交 |
| pages/review | 复习台账：学科与状态筛选、条目详情、登记复测结果 |
| pages/result | 可恢复查询、五态结果、订正复测状态、核查状态、补充材料、交付状态与成果下载 |
| pages/history | 历史任务（类型、轮次、状态、资料区间、摘要、待补充项、同步状态） |
| pages/settings | 学习设置：学期起始日期、默认年级、学科清单；服务端状态 |
| pages/mistakes | 错题本（人工收藏；空不代表全对），提供复习台账入口 |
| pages/mine | 剩余次数、学习设置入口、记录同步状态、引擎与技能就绪状态、服务器地址、重新登录 |

注意：结果页保留「AI 批改仅供参考」提示，建议上线审核时保留。
