# 学习助手小程序 · 前端说明

后端代码在上一级目录（`app/`），先看 `../README.md` 把服务跑起来。

## 导入到微信开发者工具

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram` 目录
2. 填入小程序 **AppID**
3. 打开 `utils/config.js`，把 `BASE_URL` 改成你的**业务后端**地址

> 这里只填本服务地址。Hermes 地址与密钥属于服务端内部配置，**不要**出现在小程序里。

## 本地调试

- 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
- 手机预览需打开调试模式才能访问未备案域名

## 登录与会话

- `app.js` 启动时调用 `wx.login` 换会话令牌，令牌存本地并在请求头 `Authorization: Bearer` 中携带
- 令牌失效（401）时自动重新登录并重试一次
- 「我的」页可查看当前 openid，便于加入服务端 `auth.allowed_openids` 白名单

## 提交任务

- 首页支持任务类型：作业批改 / 学习问答 / 周报分析 / 针对性训练 / 复测
- 图片逐张上传并显示状态（待上传/上传中/已上传/失败），失败重试不会重复上传已成功的图片
- 提交时带 `Idempotency-Key`，网络抖动重试不会重复创建任务、也不会重复扣次

## 结果页状态

| 状态 | 含义 | 可以做什么 |
|---|---|---|
| 排队中 / 执行中 | 服务端正在执行 | 可离开页面，返回后自动继续查询 |
| 待补充材料 | 结果已产出但缺材料 | 在页面底部提交补充材料，开启新一轮 |
| 结果未确认 | 超时或服务重启 | 不会自动重试；可补充材料后重发 |
| 失败 | 协议校验或调用失败 | 查看原因后重新发起 |
| 已完成 | 正常结束 | 查看五态结果、核查状态、下载成果 |

题目五态：答对 / 答错 / 未作答 / 待核实 / 未处理。判错题才显示「加入错题本」。

## 上线前

1. 域名完成 **ICP 备案**
2. 服务器配好 HTTPS（见 `../README.md`）
3. 小程序后台 → 开发管理 → 服务器域名，添加 `https://api.你的域名`（`request` 与 `uploadFile` 都要加）
4. 取消「不校验域名」勾选，完整跑一遍再提交审核
5. 服务端把允许使用的 openid 填入 `auth.allowed_openids`

## 页面一览

| 页面 | 功能 |
|---|---|
| pages/index | 任务类型、多图上传、文字说明、学科年级、资料区间 → 提交 |
| pages/result | 可恢复查询、五态结果、核查状态、补充材料、交付状态与成果下载 |
| pages/history | 历史任务（类型、轮次、状态、摘要、待补充项） |
| pages/mistakes | 错题本（人工收藏；空不代表全对） |
| pages/mine | 剩余次数、引擎与技能就绪状态、交付开关、服务器地址、重新登录 |

注意：结果页保留「AI 批改仅供参考」提示，建议上线审核时保留。
